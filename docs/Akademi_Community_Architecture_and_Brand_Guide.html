7. Studio Creator & Admin Governance Subscription revenue tracking (MRR in NGN), member approval/banning, lesson creator modal, community configuration.

2.2 Database Schema (SQL Blueprint)

-- Core Communities
CREATE TABLE communities (
    id VARCHAR(64) PRIMARY KEY,
    name VARCHAR(255) NOT NULL,
    slug VARCHAR(255) UNIQUE NOT NULL,
    tagline VARCHAR(255),
    description TEXT,
    category VARCHAR(100) NOT NULL,
    community_type VARCHAR(50) DEFAULT 'Tutor Masterclass',
    access_type VARCHAR(20) DEFAULT 'paid', -- 'free' | 'paid'
    monthly_price DECIMAL(10, 2) DEFAULT 0.00,
    currency VARCHAR(10) DEFAULT 'NGN',
    cover_image_url TEXT,
    avatar_url TEXT,
    creator_id VARCHAR(64) NOT NULL REFERENCES users(id),
    is_verified BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Discussion Feed Posts
CREATE TABLE community_posts (
    id VARCHAR(64) PRIMARY KEY,
    community_id VARCHAR(64) NOT NULL REFERENCES communities(id) ON DELETE CASCADE,
    author_id VARCHAR(64) NOT NULL REFERENCES users(id),
    title VARCHAR(255) NOT NULL,
    content TEXT NOT NULL,
    category_tag VARCHAR(50) DEFAULT '#General',
    is_pinned BOOLEAN DEFAULT FALSE,
    upvotes_count INT DEFAULT 0,
    created_at TIMESTAMP WITH TIME ZONE DEFAULT CURRENT_TIMESTAMP
);

-- Course Curriculum Modules & Lessons
CREATE TABLE community_modules (
    id VARCHAR(64) PRIMARY KEY,
    community_id VARCHAR(64) NOT NULL REFERENCES communities(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    order_index INT NOT NULL DEFAULT 0
);

CREATE TABLE community_lessons (
    id VARCHAR(64) PRIMARY KEY,
    module_id VARCHAR(64) NOT NULL REFERENCES community_modules(id) ON DELETE CASCADE,
    title VARCHAR(255) NOT NULL,
    lesson_type VARCHAR(30) DEFAULT 'video', -- 'video' | 'doc' | 'quiz'
    duration_label VARCHAR(50),
    video_url TEXT,
    order_index INT NOT NULL DEFAULT 0
);

2.3 Replication Roadmap & Implementation Plan

Step 1: Set Up Backend Models & REST Routes

Create database tables for communities, community_members, community_posts, community_modules, and community_events. Expose REST endpoints for list, get by slug/id, post creation, upvote toggle, and lesson progress.

Step 2: Build the Hub / Discovery View (`Communities.tsx`)

Implement search, category tabs (Data & Tech, Math & Sciences, Languages), free/paid filter pills, and community cards with member counts and prices in Naira (₦4,500/mo). Include a "Create New Community" modal for tutors and admins.

Step 3: Construct the 7-Tab Space (`CommunityDetail.tsx`)

Assemble the hero cover banner, sticky tab bar, and dynamic active view renderer. Ensure discussions allow markdown, comments, and upvotes with optimistic UI updates.

Step 4: Integrate Paystack Subscription Flow

For paid communities, initialize Paystack transaction with transaction_type = 'community_membership_subscription'. Upon verification via webhook, grant member access for 30 days.

Step 5: Connect Live Events to WebRTC Classroom

When an event is scheduled, attach a meeting_room_id. Wire the "Join Live Room" button to launch the full-screen video classroom at /classroom/:sessionId with lobby countdown gates.

Step 6: Gamification & Token-to-Tutoring Conversion

Award 15 XP for lesson completions and 10 XP for discussions. Enable learners to convert 100 accumulated tokens into 30 minutes of free 1-on-1 tutoring sessions with verified platform tutors.
